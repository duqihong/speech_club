# Speech Club Public Pages

## Purpose

This folder contains public-ready static support and privacy policy pages for Speech Club.

- `index.html`: support page for App Store Connect Support URL
- `privacy.html`: privacy policy page for App Store Connect Privacy Policy URL

The pages are static HTML/CSS only. They do not include JavaScript, tracking scripts, external analytics, or external fonts.

## Suggested GitHub Pages Deployment

Publish this folder as a static site through GitHub Pages or copy its contents into the repository path used for the public Speech Club support site.

Suggested URL mapping:

- Support URL: `index.html`
- Privacy Policy URL: `privacy.html`

## App Store Connect Usage

- Set the App Store Connect Support URL to the published `index.html` page.
- Set the App Store Connect Privacy Policy URL to the published `privacy.html` page.
- Update App Store Connect after publishing and confirm both URLs load publicly before submission.
